# Personality & Design Principles

## Design Philosophy

### 1. Power User Focus
Built for users who:
- Have large vaults (100+ notes)
- Value keyboard shortcuts
- Want fast, offline-capable tools
- Prefer native desktop over browser

### 2. Minimal but Complete
- No unnecessary features
- Everything needed, nothing extra
- Clean, uncluttered interface
- Focus on the task

### 3. System Integration
- Follows OS theme (dark/light)
- System tray for background operation
- Desktop entry for app launcher
- Autostart option

### 4. Local-First
- All processing happens locally
- No cloud dependencies
- Works without internet
- Fast response times

## Visual Design

### Color Scheme
- Primary: Indigo (#6366F1)
- Follows system dark/light mode
- High contrast for readability
- Subtle hover states

### Typography
- System font (SF Pro on macOS, Segoe on Windows)
- Clear hierarchy with sizes
- Monospace for code/paths

### Layout
- Sidebar navigation
- Content area with preview pane
- Status bar for feedback
- Respects window size

## Interaction Design

### Keyboard First
- All major actions have shortcuts
- Tab navigation works
- Escape to close/hide

### Immediate Feedback
- Loading states visible
- Status updates in real-time
- Error messages clear

### Context Menus
- Right-click on results
- Quick actions without extra clicks

## User Profile (Target)

### Who This Is For
- Developers and technical users
- Knowledge workers with large vaults
- People who value privacy/control
- Users who prefer desktop apps

### Who This Is NOT For
- Casual note takers
- Users needing multi-user access
- Those preferring mobile apps
- Non-technical users

## Inspirations

- Spotlight/Alfred search
- Obsidian's sidebar navigation
- Notion's clean layouts
- Raycast's quick access
